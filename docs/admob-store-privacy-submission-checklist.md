# AdMob 스토어 개인정보 공개 체크리스트

이 문서는 AdMob 배너 광고가 포함된 첫 앱 버전을 App Store와 Google Play에 제출할 때 개인정보 공개 항목을 함께 갱신하기 위한 운영 체크리스트다.

## 적용 시점

- 현재 스토어 배포본에 AdMob 코드가 포함되지 않았다면 스토어 개인정보 공개를 먼저 게시하지 않는다.
- 광고가 포함된 빌드를 제출하는 시점에 아래 App Store와 Google Play 항목을 반영한다.
- SDK 버전을 변경했다면 제출 전에 Google 공식 공개 안내와 SDK의 `PrivacyInfo.xcprivacy`를 다시 확인한다.

기준 버전:

- `react-native-google-mobile-ads`: `16.0.3`
- Google Mobile Ads SDK(Android): `24.9.0`
- Google User Messaging Platform(Android): `4.0.0`
- Google Mobile Ads SDK(iOS): `12.14.0`
- Google User Messaging Platform(iOS): `3.1.0`

권장 순서:

1. 광고 포함 빌드를 TestFlight 또는 Play 내부 테스트에서 검증한다.
2. App Store Connect와 Google Play Console에 아래 공개 항목을 반영한다.
3. 각 콘솔의 미리보기에서 광고 관련 변경만 추가됐는지 확인한다.
4. 개인정보 공개와 광고 포함 앱 버전을 같은 제출 작업으로 진행한다.

## 2026-08-30 완료 상태

AdMob의 **개인 정보 보호 및 메시지**에서 다음 메시지를 Android와 iOS 앱 모두에 게시했다.

| 메시지 | 적용 대상 | 언어 | 상태 |
| --- | --- | --- | --- |
| `SKURI European regulations` | EEA, 영국, 스위스 | 영어(`en`) | 게시됨 |
| `SKURI US state regulations` | 현재 및 향후 지원되는 모든 미국 주 | 영어(`en-US`) | 게시됨 |

- 유럽 메시지에는 `동의`, `동의하지 않음`, `옵션 관리` 선택지를 제공한다.
- 미국 주 메시지에는 개인정보 판매·공유 허용/거부 선택지를 제공한다.
- 별도 IDFA 설명 메시지는 만들지 않는다. iOS ATT 안내는 기존 앱 흐름을 유지한다.
- 메시지는 게시 후 앱에 반영되기까지 최대 1시간이 걸릴 수 있다.
- App Store Connect와 Google Play Console의 개인정보 공개 항목은 아직 수정하지 않았다.

## App Store Connect

경로: **App Store Connect → 스쿠리 - SKURI → 배포 → 앱 개인정보 보호**

기존 공개 항목을 삭제하거나 축소하지 말고 아래 AdMob 관련 항목만 추가·보완한다.

### 새로 추가할 데이터 유형

| 데이터 유형 | 사용 목적 | 사용자 신원에 연결 | 추적에 사용 |
| --- | --- | --- | --- |
| 제품 상호작용 | 앱 기능, 타사 광고, 개발자의 광고 또는 마케팅, 분석 | 예 | 아니요 |
| 광고 데이터 | 타사 광고, 개발자의 광고 또는 마케팅, 분석 | 예 | 아니요 |
| 충돌 데이터 | 분석 | 아니요 | 아니요 |
| 성능 데이터 | 앱 기능, 타사 광고, 개발자의 광고 또는 마케팅, 분석 | 아니요 | 아니요 |
| 기타 진단 데이터 | 타사 광고, 개발자의 광고 또는 마케팅, 분석 | 아니요 | 아니요 |

App Store Connect의 한국어 표기는 화면 개편에 따라 `제품 상호 작용`, `비정상 종료 데이터`, `실적 데이터`처럼 다르게 보일 수 있다. 의미가 같은 항목을 선택한다.

### 기존 데이터 유형 보완

| 데이터 유형 | 유지할 내용 | 추가할 내용 | 최종 연결/추적 |
| --- | --- | --- | --- |
| 대략적인 위치 | 앱 기능 | 타사 광고, 개발자의 광고 또는 마케팅, 분석 | 신원 연결: 예 / 추적: 아니요 |
| 기기 ID | 개발자의 광고 또는 마케팅 | 타사 광고, 분석 | 신원 연결: 예 / 추적: 예 |

### 게시 전 확인

- [ ] 위 5개 데이터 유형을 추가했다.
- [ ] 대략적인 위치와 기기 ID의 목적을 보완했다.
- [ ] 기존 연락처, 정확한 위치, 사용자 콘텐츠 등 광고와 무관한 응답은 변경하지 않았다.
- [ ] 미리보기에서 `기기 ID`만 추적에 사용되는 식별자로 유지되는지 확인했다.
- [ ] 광고가 포함된 앱 버전 제출 시점에 **게시**했다.

## Google Play Console

경로: **Google Play Console → 스쿠리 - SKURI → 모니터링 및 개선 → 정책 및 프로그램 → 앱 콘텐츠 → 조치됨 → 데이터 보안 → 관리**

현재 `대략적인 위치`, `앱 상호작용`, `진단`, `기기 또는 기타 ID`는 이미 데이터 유형으로 선택되어 있다. 유형을 새로 추가하는 대신 각 유형의 처리 답변을 아래처럼 보완한다.

### 대략적인 위치

- 수집됨: 예
- 공유됨: 예
- 임시 처리: 아니요
- 필수 여부: 필수
- 목적: 기존 `앱 기능` 유지 + `광고 또는 마케팅`, `애널리틱스`, `사기 예방·보안·규정 준수` 추가

현재 앱 기능의 위치 수집은 사용자가 선택할 수 있지만, AdMob은 IP 주소에서 추정한 일반적 위치를 광고 요청 과정에서 처리한다. 따라서 데이터 유형 전체 기준으로는 `필수`로 공개한다.

### 앱 상호작용

- 수집됨: 예
- 공유됨: 예
- 임시 처리: 아니요
- 필수 여부: 필수
- 목적: 기존 `앱 기능`, `애널리틱스`, `개발자 커뮤니케이션`, `계정 관리` 유지 + `광고 또는 마케팅`, `사기 예방·보안·규정 준수` 추가

### 진단

- 수집됨: 예
- 공유됨: 예
- 임시 처리: 아니요
- 필수 여부: 필수
- 목적: 기존 `애널리틱스` 유지 + `광고 또는 마케팅`, `사기 예방·보안·규정 준수` 추가

### 기기 또는 기타 ID

- 수집됨: 예
- 공유됨: 예
- 임시 처리: 아니요
- 필수 여부: 필수
- 목적: 기존 `앱 기능`, `애널리틱스`, `개발자 커뮤니케이션`, `계정 관리` 유지 + `광고 또는 마케팅`, `사기 예방·보안·규정 준수` 추가

### 변경하지 않을 항목

- 앱 전체에 관한 `수집하는 모든 사용자 데이터를 암호화하여 전송하나요?` 답변은 현재 `아니요`를 유지한다. AdMob 통신이 암호화된다는 사실만으로 앱 전체 응답을 `예`로 바꾸지 않는다.
- `비정상 종료 로그`, `기타 앱 성능 데이터`를 AdMob 때문에 수정하지 않는다. Google의 Android 공개 안내에서 AdMob 관련 성능 정보는 `진단`에 매핑한다.
- 계정 생성·삭제, 기존 개인정보, 금융 정보, 사진 등 광고와 무관한 답변은 변경하지 않는다.

### 제출 전 확인

- [ ] 관련 4개 유형을 모두 `수집됨 + 공유됨`으로 설정했다.
- [ ] 관련 4개 유형에 광고와 사기 방지 목적을 추가했다.
- [ ] 대략적인 위치에 애널리틱스 목적을 추가했다.
- [ ] 기존 목적과 다른 데이터 유형의 응답을 보존했다.
- [ ] 5단계 미리보기에서 변경 범위를 다시 확인했다.
- [ ] 광고가 포함된 앱 버전 제출 시점에 데이터 보안 양식을 제출했다.
- [ ] **게시 개요**에서 데이터 보안 변경사항과 앱 버전 제출 상태를 함께 확인했다.

## 제출 후 검증

- [ ] AdMob에서 두 메시지가 계속 `게시됨`인지 확인한다.
- [ ] EEA·영국·스위스 테스트 기기에서 유럽 메시지와 개인정보 옵션 재진입을 확인한다.
- [ ] 지원되는 미국 주 테스트 기기에서 미국 주 메시지와 판매·공유 거부 재진입을 확인한다.
- [ ] 한국 사용자의 일반 실행 흐름에 불필요한 동의 메시지가 표시되지 않는지 확인한다.
- [ ] App Store 제품 페이지와 Google Play 데이터 보안 섹션이 제출한 답변대로 표시되는지 확인한다.
- [ ] 실제 광고 요청은 동의 상태 확인이 끝난 뒤 활성 화면에서만 발생하는지 확인한다.
